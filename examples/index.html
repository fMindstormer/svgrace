A maze that solves itself

No script runs on this page. Each cell of the maze is an SVG animation that begins when its cheapest neighbour's begins, plus the cost of stepping onto it, so the browser's animation scheduler settles the cells in order of distance. The wave you see is that order. When it reaches the exit, a trace runs back along the winning passages and lights every cheapest route in gold.

Darker cells cost more to cross. Reload to run it again. How it works
